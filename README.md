# Auto-Internal Linker for WordPress 🔗

**Auto-Internal Linker** is a lightweight WordPress plugin designed to automate internal linking, strengthen site architecture, and boost on-page SEO by automatically linking target keywords to relevant internal URLs.

---

### ✨ Key Features

* **Automated Keyword Linking:** Automatically converts predefined keywords into internal links across your content.
* **Smart Frequency Control:** Prevents over-optimization by limiting how many times a keyword is linked per post.
* **Click Tracking Ready:** Built-in support for tracking user engagement on internal links.
* **Clean & Lightweight:** Built with pure PHP, JavaScript, and WordPress best practices without bloating your site.

---

### 📥 Installation

1. Click the green **Code** button at the top of this page and select **Download ZIP** (or grab the latest version from **Releases**).
2. In your WordPress Dashboard, go to **Plugins > Add New > Upload Plugin**.
3. Upload the `.zip` file, click **Install Now**, and then **Activate**.
4. Configure your keyword-to-URL pairs under **Settings > Auto Linker**.
